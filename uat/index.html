01 / CURRENT SERVICE

Service lineup

Select the sources needed for this service and assign their physical inputs. Fader routing is managed separately in M32 channel mapping.

02 / REUSABLE DEFINITIONS

Source library

Keep more sources here than the 32 desk channels available. Only the current service lineup uses console channels.

The original mono sources and their existing assignments are retained. The new stereo item keeps each source's scene configuration as Left and Right.

Use the ↑ / ↓ controls or drag a source card to change its order. This order is saved with your configuration.

03 / PHYSICAL EQUIPMENT

Stage layout

Arrange stageboxes and radio-mic receivers. Drag equipment to position it; edit its name, model and sockets below.

Your stage equipment will appear here.

04 / PHYSICAL SIGNAL ROUTING

Stagebox input mapping

Map each stagebox XLR input directly to any available M32 physical input. Fader assignments are managed separately in M32 channel mapping.

Stagebox XLR input→M32 physical input

Choose an M32 physical input target for each stagebox input. Local and Card inputs 1–32, AES50-A/B inputs 1–48, and Aux inputs 1–6 are available. Leave unused inputs unmapped.

05 / CONSOLE CHANNEL ROUTING

M32 channel mapping

Assign each channel strip/fader to an M32 physical input. A physical input can feed multiple channel strips. FX Returns 1–4 Left/Right are internal effects-engine returns and cannot be patched from a physical input here.

M32 physical input→CH 01–32 / Aux 1–6

06 / PHYSICAL OUTPUT ROUTING

M32 output mapping

Define the equipment and systems receiving audio, then map each M32 physical output to its destination. This is separate from input mapping and desk-channel assignments.

M32 physical output→Destination equipment

Physical output assignments

Available banks: Local XLR 1–16, AES50-A/B 1–48 and Card 1–32. Unused outputs can remain unmapped.
